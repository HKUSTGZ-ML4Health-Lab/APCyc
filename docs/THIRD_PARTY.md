# Attribution and external components

The model implementation derives from [THUNLP-MT/PepGLAD](https://github.com/THUNLP-MT/PepGLAD).
The original `Copyright (c) 2024 THUNLP` MIT license is retained at the repository
root. Sidechain geometry and sequence constants retain the Generate Biomedicines
Apache 2.0 notices in their source files. APCyc-specific components include
cyclization prediction and property workflows.

External dependencies include CamSol, Firefox/geckodriver, ProsperousPlus,
BigMHC, Vina/MGLTools, Rosetta and CPSea. Install and use each under its own
terms. The adapters do not distribute those executables, services, model files
or source trees. Runtime paths and credentials are supplied locally.

CPCore/LNR structures, property tables and model checkpoints are separate
research artifacts. The repository's code license does not grant redistribution
rights for those assets. Git and source packaging exclude full datasets and
model binaries. The procedural synthetic fixture contains no benchmark structure.
